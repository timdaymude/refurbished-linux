Reawakening OS 0.3.0 — a small, quick system built for machines like this one.

Give Your Computer a Second Life.

1. Get online

Click the gear at the right of the bar, then Wi-Fi, and pick your network. The machine reconnects to it by itself from now on.

2. Open your things

Brave is the browser and it is already set up, with your files in the usual folders. Nothing else is preinstalled: add the software you want from the software window.

3. Add software when you need it

Software searches Debian’s catalogue only when you open it. Nothing is installed or updated behind your back.

4. Find anything

Press Super + Space to open the launcher, Alt + Tab to switch windows, and Super + L to lock the screen.

Cockpit
What is different here. There is no software constantly running in the background: no update checker, no indexer, no cloud sync, no telemetry. That is why this computer feels quick again. Windows programs do not run natively. If you want Microsoft 365, Outlook, OneDrive or Teams, open them in Brave yourself — none of them are installed, pinned or running in the background.
